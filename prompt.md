# Figma E2E Prompt — MailSleuth AI (Cybersecurity Startup UI)

Audience: SOC analysts & hackathon judges. Goal: upload a .eml and instantly see a complete evidence-backed forensic investigation. Build a polished, "Solid UI"-style dark dashboard — startup-grade polish, zero clutter.

## Design System (apply to ALL pages)
- Theme: Dark, depth-first. Background #0A0F1E (near-black navy), surface #111827, card #0F172A with 1px border #1E293B, subtle glow shadows.
- Accent: Electric cyan #22D3EE (primary actions/active states). Semantic: Danger #EF4444 (high risk), Warning #F59E0B (medium), Success #10B981 (low/benign), Info #3B82F6.
- Typography: Sans (Inter) for UI, Mono (JetBrains Mono) for IPs, hashes, headers, IOCs, scores. Scale: 12/14/16/20/28/36.
- Components: consistent top navbar (logo + nav tabs), left/right sidebars on analysis pages, rounded-lg cards (12px radius), pill badges with dot indicators, severity chips, progress/gauge bars, skeleton loading states, empty states.
- Grid: use 8px spacing grid, 1200–1440px frame widths, auto-layout on every component.

## Page 1 — Landing / Upload (root)
- Centered hero: logo (shield + radar), H1 "Analyze suspicious emails before they strike", sub "Upload a .eml and get a complete AI forensic investigation in seconds."
- Big dashed drop-zone card: upload icon, "Drop your .eml or click to browse", "Only .eml supported", disabled [Analyze Email] CTA. Scanning state: radar sweep / progress.
- Links: "View recent investigations", "Try sample email". Footer row: pipeline badges (SPF/DKIM/DMARC, URL & Domain Intel, AI Investigator).

## Page 2 — Investigation / Analysis Dashboard
Header: file name, verdict pill (MALICIOUS/BENIGN), timestamp, [Download Report].
- Left column (37%): Threat Level hero card — gauge 94/100, RED, "HIGH RISK", attack chips (BEC, Spoofing, Executive Impersonation). Risk-factor breakdown with mini bars (Auth +25, URL +20, Domain +20, Sender +15, Content +10, ML +4).
- Right column (63%): tabbed evidence panels.
  - Authentication tab: SPF/DKIM/DMARC rows with PASS/FAIL/NONE chips + details.
  - Sender tab: From / Reply-To / Return-Path comparison, alert "⚠ Reply-To mismatch".
  - URLs tab: list of extracted URLs with risk chips (HTTPS, shortener, punycode, IP-based) and per-URL expandable reasons.
  - Content tab: detected indicators (urgency, financial request, credential request) as checkmark list.
  - Attachment tab (if present): filename, MIME, size, SHA-256, double-extension warning.
- Bottom: ML probabilities bar (BENIGN 1 / PHISHING 92 / SPOOFING 87 / BEC 78) + AI Investigator panel with typewriter-style verdict text and evidence citation chips (EV-001).

## Page 3 — Evidence Explorer (center)
- Header: "Evidence Explorer", filter chips (Authentication, URL, Domain, Content, ML) + severity filter.
- Timeline-style vertical list of evidence cards: ID badge (EV-001), category tag, severity chip, title, one-line finding, "View source" affordance. Clicked card opens detail side panel with raw value + interpreted meaning.

## Page 4 — Forensic Report (print-ready)
The document layout on dark sheet: header (logo, case ID, date, analyst).
- Executive summary block
- Verdict banner (MALICIOUS) + Risk gauge
- Attack classification list
- Evidence table (ID * Category * Finding * Severity)
- IOCs section grouped by type: Domains, IPs, URLs, Hashes (monospace, copy buttons)
- Attack timeline: vertical stepper (Received → Authentication → Delivery → URL interaction)
- Recommendations: numbered actionable list
- Footer: "Generated by MailSleuth AI".

## Page 5 — IOC Search / Threat Intelligence
Top search bar (placeholder "Search domain, IP, hash"), filter by IOC type.
- Results table: IOC type icon, value (monospace), reputation pill, first seen, domain age, source.
- Detail drawer on row select: reputation score, WHOIS fields (registrar, age, nameservers, hosting), DNS/MX records, threat reports, related IOCs.

## Page 6 — Attack Graph
Interactive network graph canvas: node = Attacker → IP → Mail Server → Victim → Phishing URL → Fake Login. Nodes colored by type, edges with arrows, click node opens side inspector with details. Legend panel. Zoom/reset controls.

## Page 7 — History (Investigation list)
Table/grid of past investigations: filename, date, risk badge, verdict, attack type, actions (view/re-download). Search + sort. Empty state with illustration + CTA.

## Page 8 — Loading & Empty States (bonus frame)
- Analyzing state: radar sweep animation, step checklist (Parsing → Headers → Auth → URLs → ML → LLM).
- Error state: invalid file rejected with reason.
